# SCIM Interoperability Profile

This repo is home to a draft to simplify implementation of SCIM 2.0 by defining an interoperability profile that deprecates certain features of SCIM and requires implementation and usage of specific options for other features.

## Contributing

I welcome any feedback, either via the IETF SCIM working group's mailing list, direct email (located in the draft), or as an issue created against this repo.
