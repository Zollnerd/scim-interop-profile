# SCIM Interoperability Profile

SCIM 2.0's flexibility in areas like PATCH syntax, pagination, filtering, and error handling permits implementation choices that have proven to be common sources of interoperability failure. This draft defines a profile that restricts those variations and establishes required capabilities, so that conformant implementations can interoperate without integration-specific customization.

## Reading the Draft

The latest build of the main branch is available in [HTML](https://zollnerd.github.io/scim-interop-profile/draft-zollner-scim-interop-profile.html) format.
